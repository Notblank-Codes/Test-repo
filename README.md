# Test-repo

Just a repo to test what I'm learning.

## Project goal
Ingest sample data, build a small ETL pipeline, and produce a dashboard showing core metrics.

## Tech stack
- Python 3.10+
- pandas, pytest
- GitHub Actions for CI
- Optional: Docker, Streamlit or FastAPI for a dashboard

## Quickstart
1. git clone https://github.com/Notblank-Codes/Test-repo.git
2. cd Test-repo
3. python -m venv venv && source venv/bin/activate
4. pip install -r requirements.txt
5. python -m src.main  # or run notebooks/

## Layout
- data/        sample datasets
- notebooks/   exploration
- src/         scripts and modules
- tests/       unit tests
- docs/        documentation
